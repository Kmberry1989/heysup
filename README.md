# hey, sup?

A 90s retro side-scrolling multiplayer adventure game. Phone-first, flat 2D chibi art.

## The game

A married couple runs a drive-through chilli dog stand out of their back bathroom window in Kokomo. When the OPEN light flickers on, a portal opens and pulls her through — he dives in after her. They land separately in a bizarro doppelganger world stuck in the 90s. Now they're finding each other, making it worthwhile, and working on things between them.

The persistent world is a bizarro 90s suburban street: separate starter bedrooms for him and her, an arcade event plaza, and a mall food court. Minigames (Mullet Kart 64, Mall Brawl, Buck Hunt, WEEDSWEEPER, and more) and BoomBox rhythm events run as rotating scheduled events. The phone is the hub — BAM texting, TamaGotcha with Purrby, MyPlace, and more. Arch-nemeses: EMO US.

## Repo layout

- `prototype/` — playable HTML5 prototype (v2). Walkable side-scrolling street, character swap (him/her), enterable arcade, working phone with app grid and a TamaGotcha mini-app. Open `prototype/index.html` in a browser.
- `docs/` — game concept and asset-needs documents.
- `logos/` — parody logo set as SVG (`index.html` previews them all).
- `assets/` — art source files: character sprite sheets (normal + EMO US, transparent PNGs), backgrounds, phone hardware templates, Purrby stages, Squirmy mascot.
